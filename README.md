# Інтеграція YASNO Cabinet

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)

Кастомна інтеграція для Home Assistant для моніторингу даних кабінету клієнта YASNO (Україна): баланс, борг, споживання електроенергії, тарифи, показання лічильника та інформація про платежі.

## Можливості

- **Моніторинг балансу**: Поточний баланс рахунку та заборгованість
- **Споживання**: Загальне споживання електроенергії
- **Показання лічильника**: Денні, нічні або загальні показання, дата передачі
- **Тарифи**: Поточна ціна тарифу (денна/нічна або єдина)
- **Інформація про платежі**: Сума та дата останнього платежу, дата останнього рахунку
- **Передача показань**: Служба для передачі показань лічильника через Home Assistant
- **Кнопка оновлення**: Миттєве оновлення даних без очікування інтервалу
- **Журнал активності**: Ключові події відображаються в Logbook Home Assistant
- **Перезавантаження без рестарту**: Інтеграція підтримує перезавантаження через UI
- **Українська локалізація**: Повна підтримка української мови

## Встановлення

### Варіант 1: HACS (Рекомендовано)

1. Переконайтеся, що [HACS](https://hacs.xyz/) встановлений у вашому екземплярі Home Assistant
2. Додайте це репозиторій як кастомний репозиторій у HACS:
   - Перейдіть до HACS → Інтеграції
   - Натисніть три крапки (⋮) у верхньому правому куті
   - Виберіть "Кастомні репозиторії"
   - Додайте `https://github.com/avoloshyn79/ha-yasno-cabinet` як URL репозиторію
   - Виберіть "Інтеграція" як категорію
3. Знайдіть "YASNO Cabinet" у HACS та встановіть його
4. Перезапустіть Home Assistant

### Варіант 2: Ручне встановлення

1. Завантажте папку `yasno_cabinet` з цього репозиторію
2. Скопіюйте її до директорії `custom_components` вашого Home Assistant:
   ```
   <config_directory>/custom_components/yasno_cabinet/
   ```
3. Перезапустіть Home Assistant

## Конфігурація

1. Перейдіть до **Налаштування** → **Пристрої та сервіси** → **Додати інтеграцію**
2. Знайдіть "YASNO Cabinet" та виберіть його
3. Введіть наступну інформацію:
   - **Назва**: Дружня назва для вашого екземпляра інтеграції
   - **Базовий URL API**: `https://app.yasno.ua` (за замовчуванням)
   - **Сесійний cookie**: Ваш cookie аутентифікації з сайту YASNO
   - **ID особового рахунку**: Необов'язково — якщо у вас кілька рахунків
   - **Інтервал оновлення**: Як часто оновлювати дані (у хвилинах, за замовчуванням: 1440)

### Як отримати сесійний cookie

1. Відкрийте браузер та перейдіть на [https://yasno.ua/](https://yasno.ua/)
2. Увійдіть до свого особистого кабінету
3. Відкрийте інструменти розробника браузера (`F12` або `Ctrl+Shift+I`)
4. Перейдіть до вкладки **Network**
5. Оновіть сторінку або перейдіть до будь-якої сторінки з даними
6. Знайдіть будь-який запит до API (наприклад, до домену `app.yasno.ua`)
7. Скопіюйте повне значення заголовку `Cookie` з цього запиту
8. Вставте це значення до конфігурації інтеграції

> **Порада**: cookie зазвичай містить параметр `x_auth` або подібний — переконайтеся, що скопіюєте **повний рядок**, а не лише його частину.

### Оновлення cookie та налаштувань

Cookie та інтервал оновлення можна змінити без видалення інтеграції:

**Налаштування** → **Пристрої та сервіси** → **YASNO Cabinet** → три крапки (⋮) → **Налаштувати**

У формі налаштувань доступні поля:
- **Session cookie** — вставте новий cookie якщо попередній протермінувався
- **Інтервал оновлення** — змініть частоту опитування API (хвилини)

Після збереження новий cookie перевіряється та інтеграція перезавантажується автоматично.

## Доступні сенсори

### Баланс та платежі
| Сенсор | Опис | Одиниця |
|--------|------|---------|
| До сплати | Поточний баланс рахунку | UAH |
| Борг | Поточна заборгованість | UAH |
| Споживання | Загальне споживання електроенергії | kWh |
| Сума останнього платежу | Сума останньої оплати | UAH |
| Дата останнього платежу | Дата найостаннішого платежу | — |
| Дата останнього рахунку | Дата виставлення останнього рахунку | — |
| Номер особового рахунку | Ідентифікатор рахунку в YASNO | — |

### Тарифи
| Сенсор | Опис | Одиниця |
|--------|------|---------|
| Тариф | Назва поточного тарифу | — |
| Ціна тарифу (день) | Денна ставка *(двозонний лічильник)* | UAH/kWh |
| Ціна тарифу (ніч) | Нічна ставка *(двозонний лічильник)* | UAH/kWh |
| Ціна тарифу | Єдина ставка *(однозонний лічильник)* | UAH/kWh |

### Лічильник
| Сенсор | Опис | Одиниця |
|--------|------|---------|
| Показання лічильника (день) | Денні показання *(двозонний)* | kWh |
| Показання лічильника (ніч) | Нічні показання *(двозонний)* | kWh |
| Показання лічильника (разом) | Загальні показання *(однозонний)* | kWh |
| Дата показання лічильника | Дата останньої передачі показань | — |

### Постачальник
| Сенсор | Опис | Одиниця |
|--------|------|---------|
| Поставщик | Назва оператора системи розподілу (DSO) | — |

> **Примітка**: Сенсори тарифу та показань лічильника відображаються залежно від типу лічильника. Для двозонного лічильника показуються «день/ніч», для однозонного — «разом» та єдина ставка.

## Кнопка оновлення

На сторінці пристрою є кнопка **Оновити дані** — натискання негайно отримує свіжі дані з API та оновлює всі сенсори без очікування планового інтервалу.

## Служби (Services)

### `yasno_cabinet.update_data`
Примусове оновлення даних з API без очікування інтервалу. Аналог кнопки "Оновити дані", але викликається через автоматизацію або Developer Tools.

### `yasno_cabinet.send_meter_readings`
Передача показань лічильника до YASNO.

| Параметр | Обов'язковий | Опис |
|----------|:---:|------|
| `account_id` | Так | ID особового рахунку |
| `readings` | Так | Список показань (зона + значення) |

Приклад виклику:
```yaml
service: yasno_cabinet.send_meter_readings
data:
  account_id: "123456789"
  readings:
    - zone: "Day"
      value: 604
    - zone: "Night"
      value: 4485
```

## Приклад автоматизації передачі показань

Автоматична передача показань лічильника 27-го числа кожного місяця о 10:00.

> **Перед використанням**: замініть `123456789` на реальний ID вашого особового рахунку, а назви сенсорів — на ваші реальні сенсори лічильника.

```yaml
automation:
  - alias: "Передача показань YASNO"
    trigger:
      - platform: time
        at: "10:00:00"
    condition:
      - condition: template
        value_template: "{{ now().day == 27 }}"
    action:
      - service: yasno_cabinet.send_meter_readings
        data:
          account_id: "123456789"
          readings:
            - zone: Day
              value: "{{ states('sensor.meter_day_energy') | float }}"
            - zone: Night
              value: "{{ states('sensor.meter_night_energy') | float }}"
```

Якщо потрібно передавати показання вручну — достатньо викликати службу через  
**Інструменти розробника** → **Служби** → `yasno_cabinet.send_meter_readings`.

## Журнал активності (Logbook)

Інтеграція записує в Logbook Home Assistant наступні події:

| Подія | Коли з'являється |
|-------|-----------------|
| `Дані оновлено. до сплати: X грн, борг: Y грн` | Після кожного успішного оновлення даних |
| `Передано показання лічильника 123456789: День: 604 кВт·год` | Після успішної передачі показань |
| `Помилка передачі показань 123456789: ...` | При помилці передачі показань |

> **Примітка**: Числові сенсори (`SensorStateClass.MEASUREMENT`) — баланс, тарифи, показання лічильника —
> не з'являються в Logbook. Це стандартна поведінка Home Assistant: числові ряди зберігаються
> в статистиці та доступні через вкладку **Історія** на картці кожного сенсора.

## Перезавантаження інтеграції

Інтеграція підтримує перезавантаження без повного рестарту Home Assistant:  
**Налаштування** → **Пристрої та сервіси** → **YASNO Cabinet** → три крапки (⋮) → **Перезавантажити**

## Вирішення проблем

### Помилка аутентифікації
- Cookie закінчився або став недійсним — оновіть його через **Налаштувати** (⋮) без видалення інтеграції
- Переконайтеся, що ви скопіювали **повне** значення заголовку `Cookie`, а не лише його частину
- Вийдіть та знову увійдіть на сайт YASNO для отримання свіжого cookie

### Дані недоступні
- Переконайтеся, що обліковий запис має активний особовий рахунок
- Перевірте доступність сайту [https://app.yasno.ua](https://app.yasno.ua)
- Перевірте логи Home Assistant на повідомлення від `yasno_cabinet`

### Невірні показання або тарифи
- Перевірте, чи API повертає актуальні дані в кабінеті на сайті
- Збільшіть рівень логування для детальної діагностики:
  ```yaml
  logger:
    logs:
      custom_components.yasno_cabinet: debug
  ```
