# YASNO Cabinet for Home Assistant

Кастомна інтеграція Home Assistant для читання даних з персонального кабінету YASNO.

## Що вміє

Інтеграція підтримує читання даних з кабінету YASNO, включаючи баланс, борг, споживання, тарифи, показання лічильника та історію платежів.

### Датчики

- **Баланс** — поточний баланс рахунку
- **Борг** — заборгованість (якщо дорівнює балансу, відображається як 0.0)
- **Споживання** — загальне споживання електроенергії
- **Останній платіж** — сума та дата останнього платежу
- **Тариф** — назва поточного тарифу
- **Ціна тарифу (день)** — денна ставка тарифу
- **Ціна тарифу (ніч)** — нічна ставка тарифу
- **Показання лічильника (день/ніч/загальні)** — останні показання лічильника
- **DSO** — оператор системи розподілу
- та інші...

### Сервіси

**send_meter_readings** — передача показань лічильника на сервер постачальника

Приклад:
```yaml
service: yasno_cabinet.send_meter_readings
data:
  account_id: "123456789"
  readings:
    - zone: "Day"
      value: 604
    - zone: "Night"
      value: 4485
```

### Приклади автоматизацій

Для зручності можна створити автоматизацію для передачі показань лічильника у певний день місяця або після оновлення датчика.

Автоматизація за розкладом (наприклад, щомісяця 25 числа):
```yaml
alias: Передати показання YASNO
description: ""
triggers:
  - trigger: time
    at: "10:00:00"
conditions:
  - condition: template
    value_template: "{{ now().day == 27 }}"
actions:
  - action: yasno_cabinet.send_meter_readings
    metadata: {}
    data:
      account_id: "123456789"
      readings:
        - zone: Day
          value: "{{ states('sensor.elektroschetchik_denniy_energy') | float }}"
        - zone: Night
          value: "{{ states('sensor.elektroschetchik_nichniy_energy') | float }}"
mode: single
```

## Важливо про авторизацію

Інтеграція використовує `session cookie` для автентифікації. Це надійний та рекомендований метод.

### Як отримати `session cookie`:

1.  **Відкрийте сайт YASNO та увійдіть в особистий кабінет.**
    Перейдіть на [https://yasno.ua/](https://yasno.ua/) і виконайте вхід, використовуючи ваші облікові дані.
    
    _Тут буде зображення 1: Сторінка входу в YASNO_

2.  **Відкрийте Інструменти розробника (Developer Tools).**
    *   У **Google Chrome / Microsoft Edge**: Натисніть `F12` або `Ctrl+Shift+I` (Windows/Linux) / `Cmd+Option+I` (macOS).
    *   У **Mozilla Firefox**: Натисніть `F12` або `Ctrl+Shift+I` (Windows/Linux) / `Cmd+Option+I` (macOS).
    
    _Тут буде зображення 2: Як відкрити DevTools_

3.  **Перейдіть до вкладки "Application" (Застосунок) або "Storage" (Сховище).**
    У лівій панелі навігації знайдіть розділ "Cookies" і розгорніть його. Знайдіть записи для домену `https://app.yasno.ua`.
    
    _Тут буде зображення 3: Перехід до вкладки Application/Storage та Cookies_

4.  **Знайдіть та скопіюйте значення `session cookie`**.
    Вам потрібен файл cookie з назвою, що зазвичай починається на `x_auth`. Скопіюйте **весь рядок значення** цього файлу cookie.
    
    _Тут буде зображення 4: Вибір та копіювання значення session cookie_

5.  **Вставте скопійований cookie в Home Assistant.**
    Під час налаштування інтеграції YASNO Cabinet у Home Assistant, вставте скопійований рядок у поле **Session cookie**.

Якщо `session cookie` протермінувався (інтеграція перестане отримувати дані) - оновіть його в налаштуваннях інтеграції, повторивши кроки 1-4.

## Встановлення

### Варіант 1: HACS (рекомендовано)

1. Відкрийте **HACS**.
2. Натисніть на три крапки у верхньому правому куті та виберіть **Custom repositories**.
3. Додайте посилання на цей репозиторій: `https://github.com/avoloshyn79/ha-yasno-cabinet`
4. Виберіть тип **Integration**.
5. Натисніть **Add**.
6. Знайдіть **YASNO Cabinet** у списку та натисніть **Download**.
7. Перезапустіть Home Assistant.

### Варіант 2: Вручну

1. Скопіюйте папку `custom_components/yasno_cabinet` у ваш Home Assistant `/config/custom_components/yasno_cabinet`.
2. Перезапустіть Home Assistant.

## Налаштування

1. Перейдіть в **Settings -> Devices & Services -> Add Integration**.
2. Знайдіть **YASNO Cabinet** та заповніть параметри (для `API base URL` лишіть значення за замовчуванням).
3. Вставте скопійований `session cookie` у відповідне поле.
4. Сканування стану інтеграції буде відбуватися автоматично (за замовчуванням кожні 6 годин).

## Додаткові можливості

### Сервіс оновлення даних

Ви можете примусово оновити дані з YASNO в будь-який момент, викликавши сервіс:

```yaml
service: yasno_cabinet.update_data
```

Це корисно, якщо ви бажаєте отримати найактуальніші дані одразу без очікування на автоматичне оновлення.

## Розв'язання проблем

### Помилка автентифікації

Якщо ви бачите помилку `Authentication failed`, це означає, що ваш `session cookie` вже не валідний. Повторіть кроки з отримання нового `session cookie` та оновіть його в налаштуваннях інтеграції.

### Інтеграція перестала отримувати дані

1. Перевірте, чи дійсний ваш `session cookie` (див. розділ вище).
2. Перевірте доступність сайту [https://app.yasno.ua/](https://app.yasno.ua/).
3. Спробуйте нажати на сервіс `yasno_cabinet.update_data`, щоб примусово оновити дані.
4. Перевірте логи Home Assistant для деталей помилок.
